# Jeu de la Vie

Automate cellulaire de John Conway (1970), version web interactive en JavaScript pur, sans dependance.

## Utiliser

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
npx serve .
```

## Fonctionnalites

- Lecture/pause, pas-a-pas, vitesse et zoom reglables
- Dessin des cellules a la souris ou au doigt
- Motifs predefinis : glider, vaisseau leger, pulsar, canon de Gosper, R-pentomino, gland
- Compteurs de generations et de population, coloration selon l'age des cellules
